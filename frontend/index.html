Cryptosystem Architecture & Mathematical Specification

Algorithm Pipeline:

  1. Input Conditioning: Image matrix I ∈ ℝH × W × C mapped to N = H × W coupled pixel channels.
  2. Key Expansion (HKDF-SHA256): 256-bit master key K derived into three isolated subkeys: Kperm, Kstream, Kmac — each bound to a unique domain tag.
  3. Spatial Diffusion (ChaCha20 Permutation): Deterministic Fisher-Yates shuffle driven by a 64-bit integer keystream from Kperm. Vectorized O(N log N) stable permutation.
  4. Value Confusion (ChaCha20 Keystream XOR): Ci = Pπ(i) ⊕ Si(Nonce, Kstream)
  5. Authentication (Encrypt-then-MAC): τ = HMAC-SHA256(Kmac, Header ‖ Ciphertext)
  6. Format Preservation: Embedded lossless PNG metadata chunk (tEXt chunk with key ImageCryptoMeta).
